# Amazon Review Sentiment Pipeline — Live App

Interactive Streamlit app for the Amazon Review Sentiment & Product Insights Pipeline project.

## Features
- **Live Sentiment Predictor** — DistilBERT model classifies any text you enter, in real time
- **Analytics Dashboard** — interactive charts: sentiment trends over time, category breakdowns, topic distribution, complaint word analysis
- **Data Explorer** — filter and browse the underlying review dataset

## Running locally
```
pip install -r requirements.txt
streamlit run app.py
```

## Deployment
Deployed via [Streamlit Community Cloud](https://streamlit.io/cloud) — connects directly to this GitHub repo.
